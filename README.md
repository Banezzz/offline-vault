# 离线保险库

本机使用的加密记事本，用来存放助记词、银行卡号和其他不想明文落地的内容。它不是钱包：不推导私钥，不连接区块链，也不访问银行。

页面只监听 `127.0.0.1`。保险库是一个加密文件，默认在 `~/.offline-vault/vault.ovlt`。

## 使用

在访达中双击项目里的 `启动保险库.command`，或桌面上的同名快捷方式。它会在需要时创建虚拟环境、安装依赖，然后打开 `http://127.0.0.1:41731/`。关掉弹出的终端窗口就会锁定并退出。

也可以手动启动：

```bash
cd offline-vault
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m vaultkit check
python -m vaultkit serve
```

浏览器打开终端里打印的地址，必须是 `http://127.0.0.1:端口/`。不要改成局域网地址。页面是本机前端（`vaultkit/frontend/`），样式和脚本只从这里加载，不访问外网。

命令行同样可用，主密码只会隐藏输入，不能写进参数：

```bash
python -m vaultkit init
python -m vaultkit add --kind mnemonic
python -m vaultkit list
python -m vaultkit show 冷钱包
python -m vaultkit passwd
```

`serve` 运行时会锁住文件。要再用命令行，先关掉那个窗口。

## 为什么这样建

威胁假设是：保险库文件被拷走，或者有人短暂坐到已经解锁的电脑前。不是防这台电脑上的木马。

- 整份内容用 **AES-256-GCM** 加密。盐、算法参数和密文在文件里，主密码不在。
- 密钥用 **Argon2id**（256 MiB × 8）从主密码派生。在较快的电脑上，解锁大约要一秒，并短时间占用约 256 MB 内存。参数写在文件里，以后改默认值也不会打不开旧库。超过这个成本的参数会被拒绝，避免别人改文件把内存打满。
- 每次保存都换新的 nonce。关联数据绑住这个库的 id，不能把另一份密文换进来。
- 写入先落到同目录临时文件，fsync 后再替换。文件权限是 `0600`。
- 解锁后，内存里只留派生密钥，用来列出标题。助记词、卡号、备注的查看、修改、删除都要再输入主密码。
- 连续输错会变慢，查看时错太多次会锁定。空闲默认 3 分钟，页面上可以改成 1–15 分钟。
- 英文助记词会做 BIP39 校验，用来发现抄错的词。校验不过默认不保存。这只检查词表和校验和，不会算出地址或私钥。
- 页面不加载任何外部脚本、字体或图片。请求必须带本站才会加的头，并且拒绝不对的 `Host` / `Origin`，避免别的网页借你的浏览器来读。

主密码按输入的原始 UTF-8 使用，不改大小写，也不做 Unicode 规范化，空格算数。BIP39 口令则按规范做 NFKD。

## 它挡不住什么

- 你输入密码时电脑上已经有键盘记录或远程控制。
- 有人看着屏幕，或者系统拼写检查把单词送了出去。页面已关掉拼写检查，系统级的还要你自己关。
- 主密码太短、被重复使用，或者和浏览器云同步的密码库绑在一起。
- 文件只有一份，磁盘又坏了。加密不能代替备份。
- 主密码忘了。没有找回，这是故意的。

助记词如果对应着有钱的钱包，加密文件只能是副本。请另外手抄或刻在不联网的介质上，并确认那份副本没被拍照。

不要把 `vault.ovlt` 放进 iCloud、网盘、桌面同步目录或 git 仓库。程序发现这种路径会提醒，但不会替你搬文件。

## 备份

复制 `vault.ovlt` 这一个文件即可。页面底部和 `python -m vaultkit path` 会显示文件的短校验值，用来确认 U 盘上的副本是同一份。校验值不是密钥。

换电脑时，复制这个文件，安装同样的程序，用原来的主密码打开。

## 自检

```bash
python -m unittest discover -s tests
python -m vaultkit check
```

`check` 会跑一次真正的 Argon2id，并告诉你这台机器上大约要几秒。那就是每次解锁的正常等待，也是离线穷举会变慢的原因。
